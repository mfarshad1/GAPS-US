# GAPS-US

Graph-Based Active Path Sampling for Free-Energy Landscape Reconstruction Using Umbrella Sampling.

## Overview

GAPS-US combines graph-based adaptive sampling, Gaussian process regression, and umbrella sampling to reconstruct free-energy landscapes efficiently.

## Benchmark systems

1. Müller–Brown potential
2. Alanine dipeptide
3. Lennard-Jones trimer with Axilrod–Teller–Muto three-body interactions

## Main code

`unified_GAPS_US-v4.py` — unified implementation of the GAPS-US framework.

## Plotting

The `plotting/` directory contains scripts for generating manuscript and Supporting Information figures.

## Notes

Simulation parameters, dependencies, and required input files should be checked before running the code on a new computing system.
